# よるを浄める（仮題）｜設計メモ

セミナー課題で作ったネオンシューターを、水晶ゆめの作品に作り替える。
**ゼロから作り直さない。** いまの `neon-shooter.html` を土台に、見た目と言葉を置き換える。

タイトルは仮。他の候補: 「よるのかけら」「しずかな夜明け」「Purify the Night」

---

## 何を変えるのか

**遊び方は変えない。** 変えるのは「これは何をしているゲームか」の意味づけだけ。

| いまの意味 | 変えたあと |
|---|---|
| 敵を撃ち落とす | 夜の靄を**浄化する** |
| 自機（三角形） | **ルナ**（光る水晶玉と猫耳のシルエット） |
| 弾 | 水晶の光の粒 |
| スコア | 今夜、**浄めた数** |
| 残機（LIVES） | **こころ**（♡） |
| ゲームオーバー | **また明日**（責めない終わり方） |
| もう一度あそぶ | **もう一度、夜を歩く** |

「撃つ」「倒す」「敵」という言葉を画面から消す。**浄める・光にかえる・靄**に置き換える。

---

## 世界観

夜の中を、ルナがひとりで歩いている。
向かってくるのは、誰かの心に溜まったもやもや。倒す相手ではなく、**光に還すもの**。

- **責めない**。失敗しても「また明日」で終わる
- **急かさない**。時間制限で追い立てない
- **静かに光る**。派手な爆発ではなく、**ほどけて光の粒になる**

CLAUDE.md の「読者を責めない・急がせない」を、ゲームの中でも守る。

---

## 見た目

配色はいまのネオンのままでよい（**ゆめのスレッズ側の顔と地続き**なので、変える必要がない）。

| 要素 | 見た目 |
|---|---|
| 自機（ルナ） | 淡く光る紫の球。上に小さな猫耳のシルエット。後ろに白い尾の光 |
| 弾 | 白〜淡紫の小さな光の粒 |
| 靄（敵） | 輪郭のぼやけた暗い塊。3種類は形と動きで区別する |
| 浄化の瞬間 | 破裂ではなく、**ふわりとほどけて光の粒が散る**。音も柔らかく |
| 背景 | 星が流れる夜空（いまのまま） |

**イラストはタイトル画面に1枚だけ使う。** ゲーム中は図形のまま。
40ピクセル程度に縮むと、細かい絵は潰れて判別できないため。

タイトル画面用の画像: `illust/luna-title.png`（`card-1.png` の構図が流用できるかもしれない）

---

## スマホ対応（必須）

**ゆめの読者はスマホが中心。** キーボード前提のままでは、ほとんどの人が遊べない。

- 指でルナをドラッグして動かす（画面のどこを触ってもよい）
- **光は自動でこぼれる**（発射ボタンは置かない。指で画面が隠れるため）
- オーバードライブは画面右下の小さなボタン
- パソコンでは今まで通りキーボードでも動く
- 画面サイズに合わせて収まる。回転しても崩れない
- ホーム画面に戻ってから戻ってきても、ポーズして再開できる

## 作り方

ローカルのセッションで、既存の `neon-shooter.html` を渡して作り替える。
**遊んで確かめられる環境で作ること。** 見た目と手触りを直す作業なので、
実際に触りながらでないと調整できない。

置き場所は `labs/` の中（公式サイトのトップには出さない）。
