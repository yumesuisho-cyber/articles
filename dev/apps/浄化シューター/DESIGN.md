# よるを浄める（仮題）｜設計メモ

セミナー課題で作ったネオンシューターを、水晶ゆめの作品に作り替える。
**ゼロから作り直さない。** いまの `neon-shooter.html` を土台に、見た目と言葉を置き換える。

タイトルは仮。他の候補: 「よるのかけら」「しずかな夜明け」「Purify the Night」

---

## 何を変えるのか

**遊び方は変えない。** 変えるのは「これは何をしているゲームか」の意味づけだけ。

| いまの意味 | 変えたあと |
|---|---|
| 敵を撃ち落とす | 夜の靄を**浄化する** |
| 自機（三角形） | **ルナ**（光る水晶玉と猫耳のシルエット） |
| 弾 | 水晶の光の粒 |
| スコア | 今夜、**浄めた数** |
| 残機（LIVES） | **こころ**（♡） |
| ゲームオーバー | **また明日**（責めない終わり方） |
| もう一度あそぶ | **もう一度、夜を歩く** |

「撃つ」「倒す」「敵」という言葉を画面から消す。**浄める・光にかえる・靄**に置き換える。

---

## 世界観

夜の中を、ルナがひとりで歩いている。
向かってくるのは、誰かの心に溜まったもやもや。倒す相手ではなく、**光に還すもの**。

- **責めない**。失敗しても「また明日」で終わる
- **急かさない**。時間制限で追い立てない
- **静かに光る**。派手な爆発ではなく、**ほどけて光の粒になる**

CLAUDE.md の「読者を責めない・急がせない」を、ゲームの中でも守る。

## 見た目

配色はいまのネオンのままでよい（**ゆめのスレッズ側の顔と地続き**なので、変える必要がない）。

| 要素 | 見た目 |
|---|---|
| 自機（ルナ） | **SDキャラのスプライト**（`illust/luna-sprite.png`）。下記参照 |
| 弾 | 白〜淡紫の小さな光の粒 |
| 靄（敵） | 輪郭のぼやけた暗い塊。3種類は形と動きで区別する |
| 浄化の瞬間 | 破裂ではなく、**ふわりとほどけて光の粒が散る**。音も柔らかく |
| 背景 | 星が流れる夜空（いまのまま） |

### 自機はルナのスプライトにする（2026-08-05 決定）

普通のイラストを縮めると潰れるが、**最初からアイコンとして描いたSDキャラなら小さくても判別できる。**
ゲームのマスコットアイコンと同じ考え方。

- 画像: `illust/luna-sprite.png`（背景透過・正方形・枠いっぱい）
- 残す特徴は3つだけ: 猫耳フード・紫の瞳・水晶玉。細かい装飾は削ってある
- 表示サイズは 56〜64px 程度（三角形の頃より少し大きくてよい）
- 描画時、スプライトの後ろに淡い紫の光（glow）を敷くと、夜空から浮き上がる
- **画像が読み込めないときは、元の図形（光る球＋猫耳）で動くこと**（フォールバック必須）
- 被弾の点滅・無敵時間の表現は、絵を変えずにコード側（透明度の明滅）でやる

タイトル画面用の画像は別: `illust/luna-title.png`（`card-1.png` の構図が流用できるかもしれない）

## にぎやかさの足し方（2026-08-05 追加。初版が地味すぎたため）

方向は「派手」ではなく**「豪華」**。点滅や爆発ではなく、光の量と変化で満たす。

### おおきな靄（ボス）

浄めた数が一定（30ごとなど）に達すると、**溜まりに溜まった、おおきな靄**が現れる。
強い敵ではなく「浄めるのに時間がかかる、大きなもやもや」。意味づけは通常の靄と同じ。

- 画面上部にゆっくり現れ、漂う。ときどき小さな靄をこぼす
- HPバーは出さない。かわりに**光の輪**が靄のまわりに少しずつ満ちていき、
  満ちきったら浄化完了（「削る」ではなく「満たす」の表現）
- 浄めきった瞬間は、ひときわ大量の光の粒がほどけて、**こころが1つ戻る**（ご褒美はやさしさ）
- 出現の予告は、画面が一瞬しんと静かになる程度。警告音やWARNING表示は出さない

### 夜空の変化（進行の実感）

浄めた数が増えるほど、**夜空がほんの少しずつ明るくなっていく**。
深い紺 → 藍 → 夜明けの気配。ゲームオーバーの「また明日🌙」に地続きでつながる。
背景に大きな月をひとつ置き、靄を浄めるたびに月がわずかに明るくなるのもよい。

### 浄化エフェクトの増量

- 光の粒の数を増やし、金色の星屑を少し混ぜる
- 連続で浄めると、粒がすこし華やかになる（コンボの静かな表現）

### タイトル画面

初版は文字だけで寂しかった。**ルナを出す。**

- `illust/luna-title.png` があればそれを表示
- 無ければ `illust/luna-sprite.png` を大きめに表示して、ふわふわ上下に浮かせる
- まわりに光の粒を漂わせ、タイトル文字の後ろに大きな月

## スマホ対応（必須）

**ゆめの読者はスマホが中心。** キーボード前提のままでは、ほとんどの人が遊べない。

- 指でルナをドラッグして動かす（画面のどこを触ってもよい）
- **光は自動でこぼれる**（発射ボタンは置かない。指で画面が隠れるため）
- オーバードライブは画面右下の小さなボタン。実装では**「しずけさ」**という名前になった
  （満ちると押せて、しばらく時がゆっくり流れる）。この名前を採用する
- **ボタンはタッチとクリックの両方に反応させる**（touchstart だけだとPCで押せない。
  2026-08-05に発生）。キーボードにも割り当てる。満ちて押せる状態は見た目で分かるようにする
- パソコンでは今まで通りキーボードでも動く
- 画面サイズに合わせて収まる。回転しても崩れない
- ホーム画面に戻ってから戻ってきても、ポーズして再開できる
