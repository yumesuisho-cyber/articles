# illust/ — 公式サイトの画像

イラストはここに置きます。ファイル名は下記のとおりにしてください（HTMLがこの名前で参照します）。

| ファイル名 | サイズ | 状態 |
|---|---|---|
| `hero.png` | 1920×1080 | 生成済み（2026-08-04） |
| `about.png` | 900×1200 | 生成済み（2026-08-04） |
| `work.png` | 1600×900 | 生成済み（2026-08-04） |
| `ogp.png` | 1200×630 | 生成済み・**要トリミング**（16:9から上下を3〜4%ずつ切る） |
| `favicon.png` | 512×512 | 生成済み・**要確認**（16pxに縮小して判別できるか） |
| `card-1〜4.png` | 800×800 | 未生成（任意） |

## 書き出し前のチェック

- 1枚 300KB 以内（スマホの読者が多いため）
- PNGで保存。可能ならWebPに変換するとさらに軽くなる
- 指定サイズより大きめに生成 → 縮小、の順で作ると輪郭がきれい

## 画像がまだ無くても

HTMLは画像が無くても崩れないように作ってあります（altとプレースホルダの背景色が入ります）。
順番に差し替えていけば大丈夫です🌙
