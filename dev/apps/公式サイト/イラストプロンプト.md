# 公式サイト用イラストプロンプト（サイズ設計込み）

`.claude/skills/reference` の考え方で作っています。
**見た目（髪色・瞳・服）は参照画像に任せて書きません。** 参照だけでは崩れやすい
「体型・必ず残す特徴」と、場面ごとに変えたい「表情・ポーズ・構図」だけを書いています。

**参照画像は全カットで使います。** 1枚目にゆめ、2枚目にルナ（キャラ設定シートの立ち絵）。
ルナ単体のカットは、ルナの画像だけを参照に入れてください。

---

## 必要なカット一覧

| # | ファイル名 | 比率 | 書き出しサイズ | 使う場所 | 優先度 |
|---|---|---|---|---|---|
| ① | `hero.png` | 16:9 | 1920×1080 | トップの一番上 | **必須** |
| ② | `about.png` | 3:4（縦） | 900×1200 | 私について | **必須** |
| ③ | `work.png` | 16:9 | 1600×900 | お仕事のご依頼 | **必須** |
| ④ | `ogp.png` | 16:9で作って 1200×630 に切る | 1200×630 | SNSでシェアされた時 | **必須** |
| ⑤ | `favicon.png` | 1:1 | 512×512 | ブラウザのタブ | 推奨 |
| ⑥ | `card-1〜4.png` | 1:1 | 800×800 ×4枚 | 活動カード4枚 | 任意 |

**④のOGPが一番人目に触れます。** noteやXでリンクを貼ったとき、
本文より先にこの画像が見られます。ここは省かないでください。

保存先は `illust/` フォルダです。

---

## 書き出しの決まり（全カット共通）

- **形式は PNG**。生成後、可能なら WebP に変換すると軽くなります
- **1枚 300KB 以内**を目安に。ゆめの読者はスマホ中心なので、重いと離脱します
- 生成は指定より大きめ（例: 2048px）で行い、**あとから縮小**すると輪郭がきれいです
- 文字は入れないでください。文字はHTMLで置きます（あとで直せる・検索に引っかかる・翻訳される）

## ① hero.png ｜トップ（16:9 / 1920×1080）

最初に目に入る一枚。**朝の光**にします。サイトが白ベースなので、背景も明るく抜けている方が馴染みます。

**構図の注意**: 左半分に名乗りの文字が乗ります。**人物は右寄り、左は空けてください。**
スマホでは左右が切られて中央だけ見えるので、**2人は中央寄りに置き、画面の端ギリギリには置かない**でください。

```
参照画像のキャラクターを2人並べて描いてください。

1人目（ゆめ）: すらりとした大人の女性。やさしい佇まい。金の星のブローチと、淡く光る宝石のネックレスは必ず残す。
2人目（ルナ）: 小柄な女の子で、ゆめより頭ひとつ以上背が低い。猫耳フード、白いふわふわのしっぽ、水晶玉のペンダントは必ず残す。

場面: 朝のやわらかい光が差し込む窓辺に、2人が並んで立っている。ゆめは少し首をかたむけて、やさしく微笑みながら正面を見ている。ルナはゆめのそばで、両手で水晶玉を抱えて楽しそうにしている。

構図: 横長16:9。2人は画面のやや右寄りに配置し、左側の約4割は文字を置けるように明るく空けておく。ただし2人を画面の右端に寄せすぎない。膝上まで。
雰囲気: 静けさとあたたかさ。白と淡い光を基調に、紫と金がアクセントとして小さく効いている。ふわりと舞う光の粒。
背景: 白に近い明るい室内。奥はやわらかくぼかす。
文字なし、テキストなし、サインなし、ロゴなし。アニメ調・高品質。
```

## ④ ogp.png ｜SNSシェア用（1200×630）

**リンクを貼ったときに表示される看板です。** 小さく表示されるので、
ヒーローの使い回しではなく、**2人の顔がはっきり見える寄り**にします。

**作り方**: 16:9で生成 → 上下を少し切って 1200×630 にトリミング。
**顔が切れないよう、人物は中央の高さに置いてください。**

```
参照画像のキャラクターを2人並べて描いてください。

1人目（ゆめ）: すらりとした大人の女性。やさしい佇まい。金の星のブローチと、淡く光る宝石のネックレスは必ず残す。
2人目（ルナ）: 小柄な女の子で、ゆめより頭ひとつ以上背が低い。猫耳フード、白いふわふわのしっぽ、水晶玉のペンダントは必ず残す。

場面: 2人が並んで、静かに微笑みながらこちらを見ている。ゆめは穏やかに、ルナは少し嬉しそうに。

構図: 横長16:9。2人を画面中央に大きめに配置し、胸から上のバストアップ。顔は画面の高さの中央に置く。上下に余白を残す（あとで上下を切るため）。
雰囲気: 明るくやわらかい。ひと目で「やさしい人だ」と伝わること。
背景: 白に近い明るい背景。淡い紫のグラデーションと小さな光の粒。ごちゃつかせない。
文字なし、テキストなし、サインなし、ロゴなし。アニメ調・高品質。
```

## ⑤ favicon.png ｜タブのアイコン（1:1 / 512×512）

**ブラウザのタブでは 16〜32px まで縮みます。** 顔を入れると潰れて何も見えません。
なので**人物ではなく、象徴的なモチーフ1つ**にします。

```
シンプルなアイコンを1つ描いてください。

題材: 淡く光る紫の水晶玉。まわりに金の細い三日月と小さな星がひとつずつ。
構図: 正方形1:1。モチーフを中央に大きく、余白を広めに。
配色: 紫（薄紫〜濃紫）と金の2色を主役に。背景は白。
質感: フラットで、輪郭がはっきりしていること。細かい模様や細い線は入れない。極小サイズに縮小しても形が分かること。
文字なし、テキストなし。アニメ調のシンプルなアイコン。
```

**参照画像は使わなくて構いません**（人物が入らないため）。
ルナの水晶玉ペンダントの色味に寄せたい場合だけ、ルナの画像を参照に入れてください。

## 生成のコツ

- **1枚ずつ作ってください。** まとめて頼むと、身長差やアクセサリーが崩れやすくなります
- 2人が並ぶ絵は「ゆめの方が頭ひとつ以上背が高い」を必ず守らせてください。**ここが一番崩れます**
- 気に入らなければ、変えるのは**表情とポーズだけ**にしてください。見た目の描写を足すと、参照画像から離れていきます
- **①と④は同じ日のうちに作る**と、絵の雰囲気が揃います。日をまたぐと画風がぶれることがあります

## 没カットの使い道

うまくいかなかったカットは、**noteメンバーシップの「没イラスト公開」に回せます。**
消さずに取っておいてください🌙
