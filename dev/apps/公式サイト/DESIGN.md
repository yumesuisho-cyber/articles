# 水晶ゆめ 公式サイト｜DESIGN.md

このファイルだけ読めば、サイトが作れる状態にしてあります。
HTMLファイル1つ（外部ライブラリなし）で完結させます。

---

## 1. このサイトは何か

**はじめて水晶ゆめを知った人が、「この人は何をしている人か」を1分で理解して、
自分に合う場所（note / スレッズ / メンバーシップ / Patreon / お仕事の相談）へ進める玄関。**

売り込むページではありません。**静かに信頼を渡す**ページです。

読者になってほしい人の気持ち: 「気になって名前を検索してみた」「note以外にどんな人か知りたい」

読み終わったときに残ってほしいもの: **安心と、ひとつの行き先**

---

## 2. トーンと文体

サイトの文章は、note記事と同じ人格で書きます。

- やさしさ・共感・静けさ・余韻
- 断定を避け、提案の形にする（「〜かもしれません」「〜してみてください」）
- 一人称は「私」
- 絵文字は 🌙 💫 を中心に、ごく控えめに。1セクションに1つまで
- 「」は使う。"" は使わない
- 煽らない。「今だけ」「絶対」「稼げる」は使わない
- **数字を盛らない。実績は下記の確定値だけを使う**

## 3. デザイン

**白ベース・文字大きめ**（課題の指定）に、水晶ゆめの世界観を重ねます。

| 項目 | 指定 |
|---|---|
| 背景 | 白〜ごく淡い紫みのグレー（#FFFFFF 〜 #FAF9FC） |
| 本文 | 濃い紫寄りのグレー（#3A3550）。真っ黒にしない |
| アクセント | 紫（#6B4FA0）と金（#C9A227） |
| 見出し | 大きく、余白を広く。詰めない |
| 本文サイズ | 18px 以上。行間 1.9 以上 |
| 余白 | 多め。**セクション間は最低 96px** |
| 角丸 | 大きめ（16px前後）。角を立てない |
| 影 | 薄く広く。くっきりした影は使わない |

**大事な考え方: 余白は「読者が自分の気持ちを置く場所」。** 情報を詰めるより、呼吸を優先します。
装飾は「静かな光」の方向で。ネオンやギラつきはこのサイトでは使いません（あちらはスレッズ側の顔）。

### 白がこのサイトの本体です（重要）

**初めて開いたときは、必ず白ベースで表示してください。**
パソコンやスマホの設定がダークテーマでも、それに合わせて夜の姿で開かないでください。

技術的に言うと、**`prefers-color-scheme` を初期表示の判断に使わない**でください。
ダークモードになるのは、**右上のトグルを押したときだけ**です（その選択は localStorage に保存し、
次回からはその人の選択を優先します）。

なぜか: このサイトは、はじめて名前を検索した人が来る玄関です。
その第一印象を、相手のパソコンの設定任せにしたくありません。
白い静けさが水晶ゆめの表の顔で、夜は「押してくれた人だけに開く」おまけにします。

ダークモードの姿: 背景 #1A1726、本文 #E8E4F0、アクセントはそのまま。

## 4. 構成（この順番）

### ① ヒーロー（＝ページの一番上。noteでいうヘッダー）

- 背景イラスト: ゆめとルナが並んでいる横長（`illust/hero.png`）
- **文字は画像に焼き込まず、HTMLで画像の上に重ねる**

重ねる文字（noteヘッダーと同じ言葉に揃えています）:

| 役割 | 文言 | 大きさの目安 |
|---|---|---|
| 大見出し | 繊細さんの心を守る言葉 | 一番大きく。48px以上（スマホは32px前後） |
| 肩書き | 水晶ゆめ🔮 当てない占い師×夢を灯す創作家 | 中くらい |
| 活動 | 占い × セルフケア × 推し活 × AIアート × 短編小説 | 小さめ。字間を広めに |

**折り返す位置を、言葉の切れ目に固定してください。** ブラウザ任せにすると
「創作家」が「創／作家」のように途中で割れます。折るなら次の位置です。

```
繊細さんの
心を守る言葉

水晶ゆめ🔮
当てない占い師×夢を灯す創作家
```

やり方は、折りたい位置に `<br>` を置くか、単語のかたまりを `<span>` で包んで
`white-space: nowrap` を掛けるか、どちらでも構いません。

**なぜ焼き込まないか**: このサイトにはサイト内検索を入れます。画像の中の文字は
検索に引っかかりません。ほかにも、スマホで小さくなって読めない・文言を直すたびに
画像を作り直す・ダークモードで色が変わらない・読み上げや翻訳が効かない、という不利があります。

**見た目はnoteヘッダーに寄せてください。** 金の細い飾り罫、明朝系の大きな文字。

**文字色は濃い紫（#3A2E5C 前後）にしてください。** hero.png は左側が
とても明るい（白に近い朝の光）ので、白文字＋暗幕にすると浮きます。
**明るい背景には濃い文字**が読みやすく、世界観も壊しません。

読みやすさの保険として、文字の後ろに**白の半透明（rgba(255,255,255,0.6) 程度）**を
うっすら敷いてください。暗幕ではなく明幕です。

ダークモードのときは、文字色を淡い紫（#E8E4F0）に反転させ、
画像の上に薄い紫黒のベールをかけて明度を落とします。

**顔を切らないこと。** 枠の高さと画像の縦横比が合わないと、上から切られて
ゆめの顔が欠けます。`object-position` を上寄り（`center top` 付近）にして、
2人の顔が必ず入るようにしてください。画面の横幅が変わっても欠けないか、
ウィンドウを狭めたり広げたりして確かめること。

### ② 私について

イラスト: ゆめが一人（`illust/about.png`）

**パソコンでは、イラストと文章を横並びにしてください。** 縦に積むと、

作ったのは、文章の横に置くためです。イラストの幅は 380px 前後まで。
スマホでは縦に積んで構いません（横幅が足りないため）。

**この順番と分量を変えないでください。** サイトは、はじめて名前を検索した人が来る場所です。

入口をやわらかく保っています。400万円という数字と「泣きました」は、

## 5. 必ず入れる機能

### サイト内検索（必須）

- 上部に検索ボックスを固定
- 入力すると本文中の一致箇所を**黄色系ではなく淡い紫でハイライト**（世界観を壊さないため）
- ヒットしないセクションは薄く（opacity を下げる）
- 「◯件見つかりました」と件数を表示
- 空にすると元に戻る

### そのほか（3つ入れる）

1. **スクロールでふわっと出る**（IntersectionObserver。上に少し動かしながらフェードイン。動きは控えめに）
2. **ダークモード切替**（右上に月と太陽のトグル。選択は localStorage に保存）
3. **FAQ の開閉**（アコーディオン。開閉はなめらかに）

## 6. 技術的な決まり

- **HTMLファイル1つ**。CSS も JS も同じファイルの中に書く
- **外部ライブラリ・外部通信は使わない**（フォントも読み込まない。システムフォントで組む）
- スマホで見たときに崩れないこと（**ゆめの読者はスマホが中心**）
- 画像は `illust/` フォルダを参照。**画像が無くても崩れないように**、alt とプレースホルダの背景色を入れておく
- 画像には `loading="lazy"`（ヒーローを除く）と `width`/`height` を指定して、
  読み込み中に文字が飛び跳ねないようにする
- `<head>` に OGP（og:title / og:description / og:image / twitter:card=summary_large_image）を入れる。og:image は `illust/ogp.png`
  - og:title は「水晶ゆめ｜繊細さんの心を守る言葉」
  - og:description は「当てない占いと、夜に灯る物語。占い・セルフケア・推し活・AIアートを届けています。」
  - **ogp.png だけは文字を焼き込んでよい**（SNSのタイムラインではHTMLが効かないため）
- ファビコンは `illust/favicon.png` を参照
- `prefers-reduced-motion` に対応（動きが苦手な人のため）

## 7. 絶対にやらないこと

- 金額・価格を書く
- 「今だけ」「値上げ予定」「今が一番お得」などの焦らせる表現
- 実績を盛る・上に書いた確定値以外の数字を書く
- 読者を責める・急かす言い方
- ギラギラした装飾、点滅、自動再生の音
