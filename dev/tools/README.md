# dev/tools/ — 執筆を助ける小さな道具

1ファイルで完結するスクリプトを置く場所です。
アプリほど大きくないもの、たとえばこういうもの。

- 原稿の形式をチェックする
- 記事一覧から目次を作る
- タグの重複を洗い出す

## 書き方の目安

リポジトリ直下の `原稿チェック_余白と改行.py` と同じ形にそろえておくと、
あとから読み返しやすくなります。

```python
# ファイル名.py
# 何をするスクリプトか（1〜2行）
# 使い方: python3 ファイル名.py 対象ファイル
# 出典・関連ルール: CLAUDE.md の該当セクション
```

## 完成したら

実際に使うようになった道具は、main に反映してもいいタイミングです。
手順は `dev/README.md` の「main に反映したいものだけ反映する手順」を見てください。
