# dev/tools/ — 執筆を助ける小さな道具

1ファイルで完結するスクリプトを置く場所です。

## いま使えるもの

### 次のカード.py — 朝活オラクルカードの選定

過去記事から「次に引けるカード」を計算します。
引き継ぎメモの使用履歴表を手で確認しなくて済みます。

```bash
python3 dev/tools/次のカード.py                # 続きの日から7日分を提案
python3 dev/tools/次のカード.py 2026-08-10     # その日から7日分
python3 dev/tools/次のカード.py 2026-08-10 3   # その日から3日分
python3 dev/tools/次のカード.py --一覧         # 全カードの最終使用日と次回使用可能日
```

14日ルール（同じカードは14日以上あける）を満たすカードの中から、
最終使用日がいちばん古いものを選びます。記事を書き足すだけで自動的に反映されます。

日付は記事のファイル名から、カード名は本文の「**カード名：**」から読んでいます。

## 書き方の目安

リポジトリ直下の `原稿チェック_余白と改行.py` と同じ形にそろえておくと、
あとから読み返しやすくなります。

```python
# ファイル名.py
# 何をするスクリプトか（1〜2行）
# 使い方: python3 ファイル名.py 対象ファイル
# 出典・関連ルール: CLAUDE.md の該当セクション
```

## 完成したら

実際に使うようになった道具は、main に反映してもいいタイミングです。
手順は `dev/README.md` の「main に反映したいものだけ反映する手順」を見てください。
