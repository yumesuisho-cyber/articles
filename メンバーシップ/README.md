# メンバーシップ/

読者・支援者・仲間との関係を運営するものをまとめた場所です。
記事そのものではなく、「誰かと関わるときに使うもの」が入っています。

| ファイル | いつ使うか |
|---|---|
| `メンバー記事紹介テンプレート.md` | メンバーさんの記事を紹介するとき（紹介文・サムネ・投稿の型） |
| `きょんちゃんのこと.md` | きょんちゃんを紹介・言及するとき（人物メモ） |
| `Patreonシリーズ管理.md` | Patreonの投稿・シリーズを管理するとき |
| `Patreon運用メモ_2026-07.md` | Patreonの決定事項・残作業 |
| `note街角占い同好会_企画情報.md` | 同好会の企画に参加するとき（ブランドタグ・記事アーカイブ） |

---

## 稼働している場所

- **noteメンバーシップ** … 没イラスト公開＋有料記事の無料開放
- **Patreon** … 海外向け・イラスト専門（高解像度壁紙・色違い・英日バイリンガル投稿）
- **note街角占い同好会** … 副部長・サムネイル担当

---

## 新しいメンバーさん・仲間を紹介するとき

1. `メンバー記事紹介テンプレート.md` で紹介文の型を確認する
2. その人のメモがこのフォルダにあれば読む（なければ作る）
3. 書いたら、次に紹介するときのためにメモを更新しておく

人物メモは「紹介文を毎回ゼロから考えないため」のものです。
その人の温度感を思い出せる程度に、やわらかく書いておくと十分です🌙
