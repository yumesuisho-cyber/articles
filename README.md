# 水晶ゆめ｜リポジトリの地図

どこに何があるかの一覧です。迷ったらここに戻ってきてください🌙

```
articles/
├── CLAUDE.md                  人格コア（司令塔）。AIが毎回読む
├── ネタ帳_記事候補ストック.md    書きたいことのストック
├── 原稿チェック_余白と改行.py    納品前の機械チェック
│
├── ルール/       AIが執筆時に読む型・プロンプト
├── 企画/         シリーズの設計書・キャラ設定
├── 記事/         原稿本体（テーマ別。案件だけ別枠）
├── 記事一覧/     公開済み記事のマガジン別インデックス
├── メンバーシップ/ 読者・支援者・仲間との関係を運営するもの
├── 引き継ぎ/     進行中の作業メモ（終わったら 完了/ へ）
└── dev/          アプリ・ツールのコード
```

**ルート直下の3ファイルは動かしません。** CLAUDE.md が実行パスや参照先として名前を指定しているので、
移動するとチェックスクリプトが失敗したり、AIが参照先を見失ったりします。

---

## ルール/ — 執筆の型

| ファイル | いつ使うか |
|---|---|
| `記事執筆プロンプト_v2.2_final.md` | 感情設計・ハルシネーション対策・チェックリスト |
| `朝活オラクルカード記事_完全運用テンプレート_v3.5.md` | 朝活オラクルカード記事を書くとき |
| `AIへの問いかけ設計_ゆめ版_v1.0.md` | 執筆ではなく戦略の壁打ちをしたいとき |
| `箇条書き記事化ワークフロー_v1.0.md` | 書きたいことが散らかってテーマが決まらないとき |
| `記事末尾導線テンプレ_v2.md` | 記事の締め・次への導線を作るとき |
| `図解イラスト制作ガイド_GPTImage2.0_v1.0.md` | 比較図・タイプ分類などの図解を作るとき |
| `イラスト生成プロンプト_v1.1.md` | note挿絵・サムネを作るとき |
| `参照イラスト_ポータブルプロンプト.md` | 参照画像からキャラを起こすとき |

## 企画/ — シリーズの設計

夜色アトリエ、ゆめとルナの旅の企画設計書と、ゆめとルナのキャラクター設定が入っています。

## メンバーシップ/ — 人との関係

メンバーさんの記事紹介の型、人物メモ、Patreon運用、note街角占い同好会。
記事そのものではなく「誰かと関わるときに使うもの」です。詳しくは `メンバーシップ/README.md`。

## 記事/ — 原稿

**テーマで分けています。** シリーズ名ではなくテーマで持つことで、
新しい連載が始まっても、既存のテーマの中に自然に入ります。

| フォルダ | 中身 |
|---|---|
| `朝活/` | 毎日の朝活オラクルカード記事（`2026-MM-DD_カード名.md`） |
| `セルフケア/` | 占い×セルフケア記事（タロット・ホロスコープ・数秘・月サイクル） |
| `推し活/` | 推し診断＆占いラボ、推し活セルフケア |
| `AIアート/` | 作品＋メイキング。企画ごとに入れ子（`夜色アトリエ/` など） |
| `自己紹介・プロフィール/` | 自己紹介記事、仕事依頼ページ |
| `日常投稿/` | シリーズに属さない日々の記事 |
| `案件/` | クライアントワーク。**案件ごとにフォルダを分ける** |

**`案件/` だけ軸が違います。** 他は「何について書いたか」ですが、案件は「誰の依頼か」です。
案件ごとに納品先も守るルールも違うので、テーマの中に混ぜず、独立させています。

```
記事/案件/
└── PolloAI_ゆめとルナの旅/    ← 幕間シリーズ（本編＋イラストプロンプト）
```

新しい案件が来たら `記事/案件/クライアント名_シリーズ名/` を作ってください。

## 記事一覧/ — 公開済みのインデックス

マガジンごとの「【保存版】記事一覧」記事です。
新しい記事を公開したら、該当するマガジンの一覧に追記します。

## 引き継ぎ/ — 作業の記憶

チャット同士は会話を直接参照できないので、ここが共有の記憶になります。

- **直下** … いま生きている作業メモ。新しいチャットはここを読んで再開する
- **完了/** … 役目が終わったもの。内容が本編に反映済みだと確認できたら削除してよい

チャットを閉じる前に、進行中の作業を `引き継ぎ/引き継ぎメモ_◯◯.md` にまとめてプッシュしてください。

## dev/ — コード

アプリ・ツールのコード置き場です。開発ブランチで作業し、
main には入れたいファイルだけを反映します。詳しくは `dev/README.md` を見てください。

---

## 新しいファイルを置くときの目安

- AIに毎回読ませたい型 → `ルール/`
- シリーズの設計・設定 → `企画/`
- 誰かを紹介する／支援者向けの運用 → `メンバーシップ/`
- note に出す原稿 → `記事/` の該当テーマ（クライアントワークは `記事/案件/案件名/`）
- 作業の途中経過 → `引き継ぎ/`
- コード → `dev/`

迷ったら `引き継ぎ/` に置いてください。あとから正しい場所に移せます。
