# 朝活オラクルカード記事｜週次作成

水晶ゆめの朝活オラクルカード記事を、前回の続きから1週間分（7本）作成する。

## 手順

### 1. 最新化

```bash
git pull origin main
```

### 2. ルールを読む

- `CLAUDE.md`（人格コア・note公開戦略）
- `ルール/朝活オラクルカード記事_完全運用テンプレート_v3.5.md`（記事の型）
- `引き継ぎ/朝活オラクルカード_引き継ぎメモ.md`（決定事項・残タスク）

**カード使用履歴の表は読まなくてよい。** 選定は下記のツールが行う。
あの表は人が読むための記録で、更新が遅れていることがある。

### 3. カードを決める

```bash
python3 dev/tools/次のカード.py
```

引数なしで、最後に記事がある日の翌日から7日分が出る。**開始日もこの出力で確定する。**

14日ルール（同じカードは14日以上あける）を満たすカードだけが、
登場していない期間が長い順に7枚出る。**基本はそのまま使う。**

入れ替えたいときは `python3 dev/tools/次のカード.py --一覧` を実行する。
「← 今すぐ使える」が付いているカードなら、どれに差し替えてもルールは守られる。

**カード名とテーマは、ツールが出力した正式版を使う。過去記事からコピーしない。**
（例: Mystic Meadow は「聖域」ではなく「サンクチュアリ」）

### 4. 季節のフックを決める

対象の7日間について、日本の行事・祝日・二十四節気・気候（梅雨、猛暑、秋の入りなど）で
合うものがあれば、記事の導入に軽く使ってよい。

**日付と行事の対応に自信がないものは使わない。**
CLAUDE.md の「嘘のエピソードは絶対に使わない」に準じる。

### 5. 確認を取る（書き始める前に、一度だけ）

次の2つを提示して、ゆめの確認を待つ。

1. 7日分の日付とカード（ツールの出力）
2. その週に使おうとしている季節フック（なければ「なし」）

### 6. 記事を書く

`記事/朝活/YYYY-MM-DD_カード名.md` の形で7本作成する。
ファイル名のカード名は英語の小文字とハイフン（例: `2026-08-17_wood-nymph.md`）。

**記事フォーマットは v3.5:**

- スリムタイトル
- プロンプトは末尾「おまけ」にコードブロックで ①ゆめ ②ルナ
- イラストセクションに「※Nano Banana 2で生成しました」は入れない
- **「🐦X用投稿文」「🧵Threads用投稿文」のセクションは書かない**
  （2026-07-24決定。X・Threadsへの朝活記事の投稿をやめたため）
- 「📣 他のSNSでも発信しています」は残す

**ハッシュタグはnote用の5個で固定:**

```
#オラクルカード #占い #セルフケア #水晶ゆめ #心をほどく言葉マガジン
```

必要な日は7個まで任意で追加してよい（立秋・山の日など）。

**余白と改行**は CLAUDE.md の文体エンジンに従う。
書き込むとフックが自動でチェックするので、指摘が出たら直す。

### 7. コミット＆プッシュ

`main` に直接置く。作業ブランチ `claude/oracle-card-articles-m6Prb` は古いので使わない。

```bash
git add 記事/朝活/
git commit -m "朝活オラクルカード ◯/◯〜◯/◯の1週間分を作成"
git push -u origin main
```

### 8. 引き継ぎメモを更新

`引き継ぎ/朝活オラクルカード_引き継ぎメモ.md` の「次回バッチ」の項目を、次の週の内容に更新する。
**カード使用履歴の表への追記は任意**（ツールが記事から読むので、選定には影響しない）。

## その週だけ特別な指定があるとき

ゆめが `/朝活` のあとに一文添えることがある。例:

- 「◯◯（テーマ）をこの週のどこかで必ず使って」
- 「◯/◯は◯◯なので季節フックに使ってOK」
- 「今週は全体を癒し寄りでまとめて」

その指定を優先する。
