# 🌙 朝活オラクルカード 新チャット用 指示文

新しいチャットで作業を再開するとき、下の「■ コピペ用」ブロックをそのまま最初のメッセージに貼る。
**毎週変えるのは開始日（○/○）だけ。** 特別な指定がある週は、最後に一文だけ足す（下の「■ 特別指定を足すとき」を参照）。

```
水晶ゆめの朝活オラクルカード記事の続きをお願いします。

まず以下3つを読んで、運用ルールと現状を把握してください（mainブランチにあります）:
1. CLAUDE.md（人格コア・note公開戦略）
2. 「ルール/朝活オラクルカード記事_完全運用テンプレート_v3.5.md」（記事の型）
3. 「引き継ぎ/朝活オラクルカード_引き継ぎメモ.md」（決定事項・カード使用履歴・残タスク）

運用ルールの要点:
- カードはSacred Forest Oracle全52枚。同じカードは14日以上あける。カード選定は下のツールで行う（使用履歴表を目で追う必要はない）。
- ハッシュタグはnote・Xとも同じ5個で固定: #オラクルカード #占い #セルフケア #水晶ゆめ #心をほどく言葉マガジン（必要な日は7個まで任意で追加可）。
- 記事フォーマットはv3.5（スリムタイトル／プロンプトは末尾「おまけ」にコードブロックで①ゆめ②ルナ／イラストセクションに「※Nano Banana 2で生成しました」は入れない）。
- 記事はmainに直接置く方針。作業ブランチ claude/oracle-card-articles-m6Prb は古いので使わない。

今回の依頼: ○/○（月）から1週間分の記事を作成して、mainにコミット＆プッシュしてください。

カードは、まず次のコマンドを実行して決めてください（日付は 2026-08-10 の形式で書くこと）。

14日ルールを満たすカードだけが、登場していない期間が長い順に7枚出ます。基本はそのまま使ってください。

季節や行事に合わせて入れ替えたいときは `python3 dev/tools/次のカード.py --一覧` を実行すると、全52枚の状況が見られます。「← 今すぐ使える」が付いているカードなら、どれに差し替えてもルールは守られます。

カード名とテーマは、ツールが出力した正式版のものを使ってください（過去記事からコピーしない）。

季節の行事や気候があれば軽くフックに使ってOK。
```

## ■ 毎週やること

- 「今回の依頼」の **日付を、その週の開始日（月曜）に差し替える**だけ（2か所。依頼文の ○/○ と、コマンドの 2026-○○-○○）。
- それ以外は基本さわらない。

先にカードだけ見ておきたいときは、自分で実行してもかまいません。

```bash
python3 dev/tools/次のカード.py 2026-08-10 7    # おすすめ順
python3 dev/tools/次のカード.py --ランダム 2026-08-10 7   # ランダムに引く
python3 dev/tools/次のカード.py --一覧          # 全52枚の状況
```

## ■ 特別指定を足すとき（その週だけ）

「今回の依頼」の末尾に一文足す。例：

- 特定カードを必ず使いたい → 「◯◯（テーマ）をこの週のどこかで必ず使うこと。」
- 行事に寄せたい → 「◯/◯は◯◯（例：海の日）なので季節フックに使ってOK。」
- テーマを縛りたい → 「今週は全体を『癒し寄り』でまとめてください。」

## ■ 覚えておくと安心なこと

- 記事は `記事/朝活/` フォルダに `2026-MM-DD_カード名.md` の形で入っている。
- カードの選定・14日ルールの管理は、**`dev/tools/次のカード.py` が一次情報**。記事ファイル名から使用日を読むので、記事を書いた時点で自動的に最新になる。**使用履歴表への手動追記は不要**（引き継ぎメモとテンプレの履歴表は、人が読むための記録として残してあるが、古い場合がある）。
- カード名とテーマは、テンプレv3.5の「全52枚カードマスターリスト」が正。ツールもここを読んでいる。過去記事は旧テーマのまま据え置く方針なので、**過去記事からテーマをコピーしない**（例: Mystic Meadow は「聖域」ではなく「サンクチュアリ」）。
- ランダムに引きたいときは `--ランダム` を付ける。14日ルールを満たすカードの中から引くので、ルールは守られる。
